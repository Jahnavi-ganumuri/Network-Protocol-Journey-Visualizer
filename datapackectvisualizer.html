🔐 Selected Protocol

HTTPS is a secure application-layer protocol used to transfer web data between a client and server.


  • Layer: Application Layer
  • Purpose: Secure web communication
  • Data: Encrypted HTTP messages

📚 Network Layers

Internet IP

🧭 Journey Steps

  • 1. Application creates the data
  • 2. Transport layer segments the data
  • 3. IP adds source and destination addresses
  • 4. Network access sends the packet
  • 5. Router forwards the packet
  • 6. Server receives and processes the packet
